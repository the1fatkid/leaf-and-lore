# Leaf & Lore 🪴🍃
Welcome to **"Leaf & Lore"**, a , a blog-themed static website dedicated to houseplant enthusiasts! It is built with **HTML** and styled using **TailwindCSS**. The website is fully responsive, ensuring a seamless experience on devices of all screen sizes. 🌿 This project demonstrates clean, modern design principles and responsive layouts using TailwindCSS.

## Features
- **Beautifully Styled**: Leveraging TailwindCSS for clean and modern aesthetics.
- **Fully Responsive**: Optimized for all devices, from desktops to smartphones.

## Demo

You can view a live demo of the project [here](https://the1fatkid.github.io/leaf-and-lore).  

## Installation
To view or modify the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/the1fatkid/leaf-and-lore.git
   ```

2. Navigate to the project directory:
   ```bash
   cd leaf-and-lore
   ```

3. Open the `index.html` file in your browser to view the site.
